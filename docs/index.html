Marker

A fast, minimal PDF annotator for Linux — highlights, ink, images, and math, without the chrome of a full office suite.

Download releases Source on GitHub

About

  • Linux-first. Built with Rust, egui, and MuPDF. Tagged releases publish an x86_64-unknown-linux-gnu binary.
  • Free software. Marker is licensed AGPL-3.0-or-later.
  • Build from source. See the repository for MuPDF system-library dependencies and the CI apt package list used on Ubuntu runners.
